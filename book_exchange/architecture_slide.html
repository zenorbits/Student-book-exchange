Flow Chart / Architecture

System Overview

Browser (Bootstrap UI) sends requests to the Flask app, which routes them to auth, listings, and search modules.

Core Backend Modules

Auth (register/login, hashed passwords) - Listings (CRUD, image upload) - Search & /api/listings JSON endpoint.

User Role Architecture

Seller: post, edit, delete & mark listings Sold. Buyer: browse, search & filter by subject, author, condition.

Technology Stack

Flask/Django backend - Jinja2 + Bootstrap 5 + JavaScript frontend - SQLite/MySQL database via database.py.
